# Order-counter — جامع الطلبات

تطبيق عربي لإدارة سجل الطلبات عن طريق مسح الباركود، مع تقويم أسبوعي وإحصاءات يومية وشهرية.

## التقنية
- React + TypeScript + Vite
- Firebase Authentication (البريد الإلكتروني وكلمة المرور)
- Cloud Firestore مع قواعد عزل بيانات المستخدمين
- ZXing لقراءة الباركود بالكاميرا

## التشغيل محلياً
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. أنشئ Firebase Web App وأدخل القيم في ملف `.env`.
4. فعّل Email/Password من Authentication وأنشئ Firestore Database.
5. انشر قواعد `firestore.rules` إلى قاعدة البيانات.
6. نفّذ:

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج: `npm run build`.

## إعداد المدير بأمان
لا يوجد تسجيل مدير من واجهة التطبيق. يجب منح Custom Claim باسم `admin: true` من بيئة موثوقة فقط (Firebase Admin SDK / Cloud Functions). لا تضع Service Account أو مفاتيح Admin SDK في التطبيق أو المستودع. بعد منح الصلاحية سجّل الخروج والدخول مجدداً أو حدّث رمز الدخول.

## ملاحظات الإصدار الأول
- كل عملية مسح ناجحة تُسجل كطلب مستقل، حتى لو تكرر رقم الباركود.
- بيانات الطلبات مرتبطة بمعرّف المستخدم، وقواعد Firestore تمنع المستخدم من قراءة بيانات الآخرين.
- لوحة المدير تعتمد على Custom Claim وتعرض الحسابات التي لديها مستندات في `profiles`.
- إعداد Firebase مطلوب قبل استخدام تسجيل الدخول والحفظ. ملف `.env.example` لا يحتوي على مفاتيح فعلية.

## النشر
يمكن نشر مجلد `dist` على Vercel أو Firebase Hosting. يجب أن يعمل الموقع عبر HTTPS حتى تسمح المتصفحات باستخدام الكاميرا.
